# 큐브 초보자 학습 서비스 구현 프롬프트

이 저장소의 docs/PRD.md를 제품 계약으로 삼아 기존 GitHub Pages 서비스를 수정하라. 목적은 실물 초보자가 자신의 촬영 큐브를 초보자 순서로 맞추며 원리를 배우는 것이다. 화면만 보기 좋게 바꾸거나 최단 풀이를 출력하는 작업으로 축소하지 마라.

## 추가 확정 조건

준비된 예제는 모두 제거한다. 예제 시작, 샘플 섞기, 임의의 완성 큐브 실험, 미래 수업용 예제 미리보기를 제공하지 않는다. 촬영 전에는 촬영 안내만 표시한다. 시범과 가상 연습은 반드시 현재 사용자의 촬영 큐브에서 유래해야 한다. 이전 예제 저장값은 자동 로드하지 않는다.

## 구현할 흐름

1. 꽃 → 옆 색까지 맞춘 흰 십자 → 첫 층 코너 → 가운데 층 → 노란 십자 → 노란 면 → 마지막 코너 자리 → 마지막 변 자리 순서를 유지한다. 실제로 이미 맞은 목표만 건너뛴다.
2. planner가 선택한 초보 패턴의 경계를 회전 목록과 함께 보존한다. 꽃은 먼저 만든 꽃잎을 매 회전 지키고, 나머지 단계는 패턴 경계에서 이미 맞춘 부분을 보호한다. 같은 면의 U U U 같은 준비 회전은 U′처럼 읽기 쉬운 한 동작으로 정리하되 전후 상태가 같음을 검사한다.
3. 기본 학습은 임의 면 버튼을 고르는 시험이 아니라 실물 따라 맞추기다. 현재 목표와 다음 회전의 색·방향·이유·돌린 뒤 확인할 모습이 같은 3D 큐브 위 반투명 안내에 나온다. 필수 퀴즈와 여러 확인 화면은 만들지 않는다.
4. 오른쪽 화살표는 안내한 동작을 실물에도 적용했다는 확인 후 예상 큐브에 같은 회전을 적용하고 다음 설명으로 간다. 왼쪽 화살표는 실제 역회전 안내와 함께 이전 예상 상태·설명으로 돌아간다. 이력은 조각과 단계의 경계 및 새로고침을 넘어 보존한다. 화살표를 정적인 미래 수업 미리보기로 연결하지 마라.
5. 단계 완료는 실제 모델의 목표와 보호 조건으로 검사한다. 정해진 패턴은 끝까지 보여준다. 꽃 완료 후 같은 큐브에서 십자로 이어간다. 최단 해법이나 다른 예제로 몰래 바꾸지 마라.
6. 시범은 복사본에서 현재 조각의 패턴을 재생하고 정확한 진행 상태로 돌아온다. 가상 연습도 복사본에서 시작하고 실제 조각의 결과로 판정한다. 가상 연습은 명확히 표시하고 실물 진도·저장값·되돌리기 이력을 덮어쓰지 마라.
7. 카메라 여섯 면 자동 전환, 같은 비디오 유지, 중심 로고 안내, 선명한 여섯 색, 색 수정, 9칸 및 물리 가능성 검사, 새로고침 보존과 명시적 초기화를 유지한다. 다시 촬영은 새 입력을 시작하되 유효 촬영 완료 전까지 기존 학습을 보존한다.
8. 기본 화면은 한 3D 큐브와 앞뒤 버튼, ⋯만으로 충분하게 구성한다. 노랑 위라는 기준과 면을 정면에서 볼 때의 회전 방향을 일관되게 설명한다. 촬영 후 강제 스크롤을 추가하지 마라.

## 구현 및 검증 순서

기존 수학 모델과 실제 3D 렌더러를 재사용한다. 교육용 메타데이터 및 설명 생성을 별도 모듈로 두어 모델과 독립 검증 가능하게 한다. 진행 상태와 임시 시범·연습을 분리하고 이전 저장값을 보존한다. 자동 테스트는 회전 모델을 흉내 내지 말고 실제 Cube 모델과 실제 계획을 사용한다.

무작위 유효 큐브 전체 단계 완성, 패턴 경계와 꽃잎 보존, 회전별 설명 필드, 이전·다음의 단계 경계 왕복, 새로고침, 시범·연습 격리, 촬영 기존 회귀 검사를 실행하라. 실제 브라우저에서 첫 꽃잎부터 십자까지 안내를 따라가고 작은 화면의 주 조작이 보이는지 확인하라. 실제 사람의 학습 효과를 자동 테스트 결과로 대신 주장하지 마라.

완료 후 PRD 요구사항별 구현·검증 기록을 docs/RESEARCH_AND_VALIDATION.md에 남기고 GitHub Pages에 배포하라. 사용자에게 PRD, 이 프롬프트, 실제 배포 링크와 변경 화면을 제공하고 미검증 항목을 구체적으로 밝히라.
