# 3×3 큐브 초보자 학습 서비스 PRD

버전 1.0 · 2026년 10월 16일

실물 큐브를 처음 잡은 사람이 자기 큐브를 촬영하고, 초보자용 층별 풀이 순서에 따라 직접 완성하도록 돕는다. 매 동작에서 무엇을 보고, 어느 색의 중심면을 어떻게 돌리며, 왜 그 동작이 필요한지, 결과로 무엇이 달라져야 하는지 함께 보여준다. 최적화 대상은 풀이 수가 아니라 이해하기 쉬운 동작의 반복, 실물과 화면의 일치, 불필요한 선택과 화면 이동의 감소다.

## 사용자와 성공의 정의

주 사용자는 회전 기호를 모르고 꽃과 십자의 차이도 아직 익히지 않은 실물 큐브 초보자다. 촬영한 본인 큐브만 사용한다. 미리 준비한 예제, 임의의 섞인 큐브, 예제 진입 버튼은 모두 제거한다. 시범과 가상 연습은 본인의 촬영 배치에서 나온 현재 조각의 시작 상태만 사용한다.

성공은 화면의 재생을 끝내는 것이 아니다. 사용자가 흰색만 맞춘 면과 옆면까지 맞춘 한 층을 구별하고, 다른 배치에서도 중심색과 조각의 색을 비교해 같은 방법을 적용하는 것이다. 제품 내부에서는 디지털 큐브의 조건 충족을 검사한다. 실물 큐브의 실제 회전 여부는 카메라로 매번 추적하지 않으므로, 사용자가 화면과 실물의 일치를 확인해야 한다. 자동 테스트 통과를 실제 초보자의 학습 성공으로 주장하지 않는다.

## 조사 근거와 채택한 교육 순서

[Rubik’s 공식 3×3 가이드](https://rubiks.com/solve-guide)는 노란 중심을 위로 유지하며 아래의 여덟 목표를 순서대로 다룬다. 중심으로 면을 구분하고, 여러 색이 붙은 한 조각을 함께 움직이는 대상으로 이해하는 설명을 출발점으로 채택한다.

[CubeSkills 초보자 과정](https://www.cubeskills.com/tutorials/the-beginners-method-for-solving-the-rubiks-cube)은 구조와 회전법을 소개한 뒤 첫 층, 가운데 층, 마지막 층, 예제 풀이를 연결한다. [J Perm 초보자 설명](https://jperm.net/3x3)은 짧은 반복 동작과 실제 예제를 함께 사용한다. 자료마다 잡는 방향과 마지막 층의 세부 순서가 다르므로, 한 서비스 안에서는 아래 순서와 노랑 위라는 기준을 일관되게 사용한다.

| 수업 | 완성 조건 | 배우는 원리 | 보호할 부분 |
| --- | --- | --- | --- |
| 1 흰 꽃 | 노란 중심 둘레 네 변에 흰색이 위를 향함 | 두 색의 변 조각 찾기, 올릴 빈자리 만들기 | 먼저 올린 꽃잎 |
| 2 흰 십자 | 아래 흰 십자와 네 옆 색이 각 중심에 연결됨 | 위에서 옆 색 정렬 후 그 색 면을 반 바퀴 내려 두 색을 함께 맞춤 | 이미 맞춘 십자와 아직 위에 남은 꽃잎 |
| 3 흰 코너와 첫 층 | 흰 코너 네 개와 옆면의 첫 줄까지 맞음 | 세 중심 사이의 자리 찾기, 짧은 넣기 패턴 | 흰 십자와 앞서 넣은 코너 |
| 4 가운데 층 | 아래 두 층이 맞음 | 노랑 없는 변 조각을 정렬하고 왼쪽 또는 오른쪽에 넣기 | 완성한 첫 층, 먼저 맞춘 가운데 변 |
| 5 노란 십자 | 위 네 변의 노랑이 위를 향함 | 위치와 방향을 구별하고 점·ㄱ·일자에서 방향 바꾸기 | 아래 두 층 |
| 6 노란 면 | 위 아홉 칸이 노랑 | 코너의 위치와 방향을 구별하고 방향 패턴 반복 | 아래 두 층, 노란 십자 |
| 7 마지막 코너 자리 | 위 코너의 옆 색까지 중심과 맞음 | 색이 위를 향해도 조각의 자리가 다를 수 있음 | 아래 두 층과 노란 면 |
| 8 마지막 변 자리 | 여섯 면 전체가 맞음 | 고정할 부분과 순환시킬 변 조각을 구별 | 코너와 아래 두 층 |

위 표는 목표 순서를 채택한 것이며 특정 자료의 모든 회전 공식을 그대로 복제한다는 뜻은 아니다. 구현은 검증된 층별 패턴 모음을 사용한다. 마지막 층은 패턴이 끝났을 때 보호 조건을 확인하고, 중간 동작에서 잠시 흐트러지는 부분을 실패로 판정하지 않는다.

## 현재 구현에서 고쳐야 할 문제

1. 돌릴 면을 사용자가 스스로 고르는 연습이 기본값이라, 아무것도 모르는 초보자가 어디서 시작할지 알기 어려웠다.
2. 다음 화살표가 현재 큐브의 다음 동작 대신 다른 수업의 정적인 미리보기로 연결됐다. 한 큐브를 실제로 완성하는 주 흐름이 끊겼다.
3. 설명 대부분이 조각 단위 또는 단계 단위여서 동작이 바뀌어도 같은 문장이 반복됐다.
4. 풀이 계획을 만들면서 반복 패턴의 경계가 평탄한 회전 목록으로 사라졌다. 교육에는 ‘어떤 패턴의 어디인가’가 필요하다.
5. 가상 연습의 성공, 예상 화면 상태, 실제 사람이 맞춘 상태를 구분해야 한다.

## 주 사용자 흐름

### 촬영

카메라 켜기 → 현재 면 촬영 → 3D 안내 큐브 전체가 다음 면으로 회전 → 나머지 면 반복 → 색과 물리 가능성 검사 → 현재 큐브의 필요한 첫 목표로 진입한다. 완료된 단계는 이유와 함께 이미 맞아 있다고 알린다. 흰 십자까지 맞은 실물을 꽃부터 다시 흐트러뜨리지 않는다.

현재 구현의 여섯 면 입력, 중심 로고 보정, 색 수정, 자동 다음 면, 카메라 유지, 새로고침 보존, 명시적 초기화는 유지한다. 작은 화면에서도 촬영 화면 자체는 한 화면에 들어가며, 촬영 후 안내 영역으로 강제로 스크롤하지 않는다. 색 개수가 틀리거나 물리적으로 불가능하면 입력을 보존하고 수정할 곳을 안내한다.

### 실물 따라 맞추기 기본 모드

한 화면에 현재 큰 목표, 다음에 돌릴 동작, 이유, 3D 큐브, 이전·다음 화살표가 있다. 처음부터 회전 기호를 외우거나 임의의 면을 선택할 필요가 없다.

- 큐브 상단의 반투명 안내에 ‘관찰 → 동작 → 이유 → 돌린 뒤 확인’을 짧게 표시한다. 이것을 네 개의 통과 화면으로 나누지 않는다.
- 움직일 조각과 돌릴 중심면을 3D에서 표시하고 실제 층 회전 화살표를 보여준다. 빨강과 주황 등 여섯 색은 선명한 단색이다.
- 사람은 설명된 동작을 실물에 적용한 뒤 오른쪽 ‘따라했어요 · 다음’을 누른다. 화면이 같은 회전을 적용하고 다음 설명으로 이어진다. 화면 상태는 사람이 적용했다고 확인한 동작의 예상 상태다.
- 왼쪽 ‘이전 동작’은 직전 예상 상태와 설명으로 돌아간다. 실물도 표시된 동작을 반대로 되돌려야 한다고 알린다. 조각·수업 경계를 넘어도 같은 이력을 따른다.
- 한 조각을 맞추면 다음 색의 같은 패턴으로 이어진다. 여섯 개의 확인 단계나 필수 퀴즈를 다시 밟지 않는다.
- 꽃을 완성하면 한 번 결과를 확인하고, 같은 오른쪽 버튼으로 십자를 시작한다. 다음 수업으로 건너뛰어 실물과 무관한 상태를 대신 표시하지 않는다.
- 코너·가운데 층·마지막 층에서는 패턴의 현재 위치를 표시한다. 중간에 목표처럼 보여도 지정된 짧은 패턴을 끝낸 뒤 보호 조건을 검사한다.

예: ‘주황 중심 위에 흰·주황 변 조각의 주황이 맞아 있어요 → 주황 중심면을 정면에서 볼 때 반 바퀴 돌려요 → 같은 조각의 흰색은 아래 흰 중심으로, 주황은 자기 중심으로 함께 갑니다 → 아래 흰색과 옆 주황이 모두 연결됐는지 보세요.’ 다음 색도 동일한 설명 구조를 사용한다.

### 시범과 가상 연습

보조 기능은 ⋯에 모은다. 시범은 현재 조각의 시작 배치에서 짧은 동작 묶음을 보여준 뒤, 따라 맞추던 정확한 상태로 돌아온다. 재생으로 실물 진도를 완료 처리하지 않는다.

가상 연습은 현재 상황의 복사본으로 시작한다. 원하는 면을 돌리며 실제 조각의 결과로 목표를 확인한다. 정해진 버튼 순서와 일치해야만 정답인 것은 아니다. 실물 따라 맞추기의 큐브·이력·진도는 수정하지 않는다. 연습을 닫으면 원래 동작과 큐브로 돌아간다. 퀴즈 정답 확인은 필수가 아니다.

### 실물과 화면이 달라진 경우

이전 동작으로 되돌리거나 ‘현재 큐브 다시 촬영’을 선택한다. 다시 촬영은 새 여섯 면 입력을 시작하되 기존 학습 기록은 유효한 새 촬영이 끝날 때까지 보존한다. 앱은 실제 큐브를 보지 않고 자동 동기화됐다고 주장하지 않는다.

## 풀이 계획과 상태 설계

계획에는 단계, 목표 조각, 현재 배치, 목표 배치, 회전 목록 외에 패턴별 시작·끝·역할을 보존한다. 회전 설명은 현재 배치와 그 회전 후의 배치를 비교해 생성한다. 임의의 자연어 모델이 회전을 만들어내게 하지 않는다.

최적화 우선순위는 ① 물리적으로 가능한 경로 ② 같은 초보 목표 순서 ③ 배운 패턴과 기준 방향 재사용 ④ 목표 경계에서 맞춘 부분 보호 ⑤ 불필요한 같은 면 반복 합치기다. 전체 최단 해법으로 바꿔치기하지 않는다.

지속 상태는 출발 촬영, 현재 예상 상태, 큰 단계, 이번 조각의 시작 배치, 다음 회전 위치, 완료 목표, 되돌리기 이력이다. 시범과 연습은 별도 임시 상태다. 이전 버전 저장값은 진행 중인 실제 예상 상태와 조각 계획을 유지한 채 옮긴다. 이전 화살표를 위한 기록에 매번 전체 풀이 계획을 복제하지 않아 저장 용량을 제한한다.

## 범위와 출시 검증

준비된 예제를 불러오는 경로는 없애고, 이전 예제 저장값도 수업으로 자동 복원하지 않는다. 이번 구현 범위는 여덟 목표를 따라가는 기본 안내, 동작별 설명, 실제 3D 회전, 앞뒤 이력, 시범과 격리된 연습, 기존 촬영 기능 유지다. 실물 자동 회전 추적, 음성 명령, 계정·서버 동기화, 속도 측정과 고급 CFOP 과정은 포함하지 않는다.

개발 검증은 무작위 큐브의 전체 완성, 모든 패턴 재생, 보호 조건, 이전·다음 왕복, 저장값 이전, 연습 격리, 촬영 회귀 검사, 실제 브라우저와 작은 화면 검증으로 한다. 별도로 실제 초보자가 설명만 보고 처음 완성하는지 관찰하고, 꽃과 십자의 차이 및 다른 색에 같은 원리를 적용하는지 확인해야 교육 효과를 검증할 수 있다. 이 사용자 평가는 자동 검사와 별개다.
