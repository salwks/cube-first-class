# 큐브 학습 조사 및 구현 검증 기록

## 참고 서비스 직접 확인

2026년 10월 16일 https://solver.cubeunstuck.com/ 에서 데모를 실행했다. 스캔·수동 입력·데모 진입을 제공하며, 실행한 데모에서는 19수와 이전·재생·다음 및 더 적은 수 찾기를 표시했다. 이것은 그 데모의 관찰값이며 모든 배치가 19수라는 뜻이 아니다.

사이트는 https://learn.cubeunstuck.com/ 을 별도 학습 앱으로 연결한다. 해당 앱의 데모는 첫 단계로 Daisy 목표와 노란 중심을 위로 잡는 안내를 보여주고, NEXT STEP으로 설명을 이어갔다. 따라서 CubeUnstuck 전체에 학습 기능이 없다는 평가는 하지 않는다. 이번 서비스는 사용자가 요청한 한국어 초보자 교육 순서와 실제 연습 흐름에 맞춰 독립적으로 구현한다.

## 교육 자료와 설계 결정

- [Rubik’s 공식 가이드](https://rubiks.com/solve-guide): 여덟 목표와 중심·변·꼭짓점 구분, 노랑 위라는 방향 기준을 채택한다.
- [CubeSkills 초보자 과정](https://www.cubeskills.com/tutorials/the-beginners-method-for-solving-the-rubiks-cube): 구조·표기 소개 뒤 층별 학습과 예제를 연결한다는 점을 참고한다.
- [J Perm 초보자 과정](https://jperm.net/3x3): 짧은 반복 동작, 상황에 따른 조각 처리와 예제 풀이를 참고한다. 공식 가이드와 잡는 방향이 달라 하나의 앱에 서로 다른 기준을 섞지 않는다.

설계 판단은 PRD에 별도로 명시했다. 학습 성과는 실제 초보자 테스트가 필요하며, 참고 서비스의 기능 설명이나 자동 모델 검사만으로 보장할 수 없다.

| EDU 05 | 시범은 임시 모델, 연습은 별도 메모리 상태. 재생·연습 성공·닫기 후 실제 상태와 안내 및 저장값 동일함을 자동·브라우저 검사로 확인. |

### 실제 브라우저에서 실행한 흐름

합성 촬영 이미지 여섯 장을 사진 업로드 입력으로 등록했다. 센터 로고와 기존 저채도 조명 fixture를 실제 PNG 디코딩 및 색 인식 경로에 통과시켰다. 정상 배치로 검사된 뒤 첫 수업으로 자동 진입했다.

이전·다음 버튼으로 꽃을 완성하고 같은 큐브 상태에서 흰 십자로 이동했다. 주황 옆 색 정렬 후 반 바퀴를 내리는 설명과 3D 화살표를 확인했다. 가상 연습에서 같은 조각을 맞춘 뒤 돌아왔을 때 실제 수업의 54칸 색과 안내 문장이 동일했다. 시범 종료 뒤에도 54칸이 동일했다. 다시 촬영으로 입력을 비운 후 수업으로 돌아가 기존 진도가 유지됨을 확인했다. 브라우저 오류 로그는 없었다.

### 검증 범위

실제 카메라 하드웨어의 조명·초점별 인식률을 이 환경에서 측정하지 않았다. 카메라 세션 재사용은 모의 스트림 회귀 검사, 사진 인식은 PNG 파일 업로드로 확인했다. 실제 초보자가 혼자 첫 완성을 하는지, 다른 배치로 원리를 전이하는지는 별도의 사용자 관찰 평가가 필요하다. 따라서 이번 결과는 구현 및 기능 검증이며 교육 효과를 입증한 사용자 실험은 아니다.

공개 배포는 GitHub Actions 검사와 배포 완료 후 확인한다.
